# Pokédex Card — Variants Exercise

A set of 3 Pokémon-themed card components (Charmander, Squirtle, Bulbasaur), built as a free-form exercise during my web design training program.

## 🎯 About this project

This was an open-ended exercise where the goal was to practice building consistent variants of the same component. I designed a Pokédex-style card and declined it across three different Pokémon types (Fire, Water, Grass), keeping the same structure while adapting colors and content for each.

## 🛠️ Built with

- Semantic HTML5
- CSS3 (custom properties, transitions)
- Google Fonts (Roboto)

## ✨ Features

- Card layout with overlapping image effect
- Hover transitions on the image and button
- Type-based badge styling, reused consistently across all three variants

## 📚 What I practiced / learned

- Structuring a "card" layout with overlapping elements (z-index, negative margin)
- Building consistent component variants (same structure, different themes/colors) — similar logic to a small design system
- Adding smooth hover transitions
- Working with box-shadow and drop-shadow for depth
